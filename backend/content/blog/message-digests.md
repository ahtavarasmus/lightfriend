Checking four inboxes “just in case” is still checking four inboxes. Lightfriend’s message digests are designed to replace that loop with a scheduled summary.

When digests are enabled, incoming items that do not need immediate attention can be grouped into one SMS. The digest can include routine messages from connected chat services and email, with compact context about who wrote and what happened.

## Choose a rhythm

You can set specific digest times, up to the product’s daily limit, or use automatic scheduling based on observed activity patterns. If nothing new has accumulated, Lightfriend does not send an empty digest.

Before composing a digest, the system filters messages already marked as seen and items classified as spam. Messages from unknown chat senders can be collapsed into a count rather than filling the summary; email remains visible because email senders are not expected to match a phone contact list.

## A summary is a starting point

An SMS digest is necessarily compact. If an item needs more context, you can ask Lightfriend about recent messages or a particular sender. Connected-provider availability still matters, and summaries can reflect imperfect AI classification.

The useful trade is straightforward: one deliberate review window instead of a day shaped by inbox checks.
